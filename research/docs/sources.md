## What this means for the code
- **Original baseline.** The algorithms in `research/lib/inference.js` are original, documented baselines (see `algorithm-card.md`), not recreations of any company's algorithm.
- **Engineering assumptions.** No numerical threshold was taken from these sources. Every threshold is an engineering assumption in `research/lib/config.js`.
- **Next step.** To use sources 1 and 4, allow `www.accessdata.fda.gov` and `arxiv.org` in this environment's network settings, or provide the PDFs. Then re-run this review and record the licence before implementing anything based on them.
