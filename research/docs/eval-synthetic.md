- **Endpoint:** next period start date: forecast point minus logged start (days). **Reference:** synthetic logged period starts (generator truth). **Exclusions:** first cycle of each person (no prior start); none other.
- **Denominator:** 256 forecast points (one per logged start after the first, per person). Leakage check: **0 violations** (each forecast uses only entries recorded before its timestamp).
- **Coverage / abstention:** 96 estimates, 160 abstentions (63%). Abstention reasons: too_few_usable_cycles 160.
- **Conditional error among the 96 estimates:** mean absolute error 2.43 days (participant-level bootstrap 95% interval 1.74–3.37 days). Signed error quantiles (days, point minus logged start): p10 -2.5, median 1, p90 3; range -15 to 14.
- **Empirical range:** contained the logged start in 77% of estimates; mean width 6.05 days. The range is shortest-to-longest of recent cycles and is **not calibrated**; this coverage figure applies to synthetic cycle lengths drawn independently, which real cycles are not.
